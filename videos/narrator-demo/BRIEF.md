## Intent

One 16:9 demo used everywhere: the top of the GitHub README, LinkedIn, and the v1.1 release. Show Narrator as a calm, charming reading companion: select text, pick a mood and voice, hear it read with the line highlighted while Lumen reads along on the Dock. Warm, a little playful, never salesy.

## Assets

- capture/assets/lumen-*.png — Lumen's ten real poses from the app (read, talk, walk1, walk2, fly, wave, listen, think, cheer, sleep), transparent.
- capture/assets/purpose.png — the real purpose box with Read, Mood and Voice rows.
- capture/assets/ask-box.png — the real Ask box.
- capture/assets/bar-reading.png, bar-following.png, bar-paused.png, bar-answer.png — the real playback bar states.
- capture/assets/app-icon.png — the app icon.

## Customizations

- Animated recreation built from the app's real parts; no screen recording.
- Narration in Narrator's own default voice (Kokoro af_heart), captions on.

## Notes

- Free, local, no API keys, no cloud voices. No paid services.
- Show the GitHub URL at the end: github.com/jain-eshan/narrator.
- Never show the user's own screen, chats or meetings.
